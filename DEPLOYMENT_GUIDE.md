# Руководство по деплою на Vercel

## Проблема: Прямые ссылки не работают на Vercel

Если API на Vercel возвращает только `directLinksAvailable: false`, это связано с ограничениями serverless окружения.

### Причины:
1. **Таймауты** - бесплатный план Vercel имеет лимит 10 секунд на функцию
2. **IP-блокировка** - Kodik может блокировать IP-адреса Vercel
3. **Сетевые ограничения** в serverless окружении

### Решение:

#### 1. Настройте переменные окружения в Vercel:

1. Перейдите в Settings → Environment Variables вашего проекта
2. Добавьте:
   - `KODIK_PUBLIC_TOKEN` = ваш токен с https://bd.kodik.biz/api/info

#### 2. Увеличьте таймаут функций:

Файл `vercel.json` уже добавлен с настройкой:
```json
{
  "functions": {
    "pages/api/**/*.js": {
      "maxDuration": 60
    }
  }
}
```

**Примечание:** Таймаут 60 секунд доступен только на Pro плане. На бесплатном плане максимум 10 секунд.

#### 3. Проверьте логи:

После деплоя проверьте логи в Vercel Dashboard → Deployments → Functions для отладки.

#### 4. Альтернативные решения:

Если проблема не решается:

**Вариант А: Используйте Vercel Pro**
- Увеличенные лимиты таймаутов (до 60 секунд)
- Лучшая производительность

**Вариант Б: Используйте другой хостинг**
- Railway.app
- Render.com
- DigitalOcean App Platform
- AWS Lambda с увеличенным таймаутом

**Вариант В: Добавьте кэширование**
- Кэшируйте результаты запросов к Kodik
- Используйте Redis или другую БД

**Вариант Г: Прокси-сервер**
- Разверните отдельный прокси-сервер для запросов к Kodik
- Используйте VPS с белым IP

## Команды для деплоя:

```bash
# Установка зависимостей
npm install

# Запуск локально
npm run dev

# Сборка
npm run build

# Деплой на Vercel
vercel --prod
```

## Проверка работы:

Локально (должно работать):
```bash
curl http://localhost:3000/api/kodik/episode?episode_id=41924
```

На Vercel (может не работать без настройки):
```bash
curl https://your-project.vercel.app/api/kodik/episode?episode_id=41924
```
