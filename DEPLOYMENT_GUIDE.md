# Руководство по деплою на Vercel

## Проблема: Прямые ссылки не работают на Vercel

Если API на Vercel возвращает только `directLinksAvailable: false`, это связано с **блокировкой IP-адресов Vercel со стороны Kodik**.

### Подтвержденная причина:
**Kodik блокирует запросы с IP-адресов Vercel** и возвращает HTML вместо JSON API.

Ошибка в логах:
```
❌ Fallback также не сработал: videoInfoResponse is not json
```

### Почему это происходит:
1. **IP-блокировка** - Kodik активно блокирует IP диапазоны облачных провайдеров (Vercel, AWS, etc)
2. **Защита от скрейпинга** - Kodik защищает свой контент от автоматического извлечения
3. **Библиотека kodikwrapper** - использует прямые запросы к Kodik API, которые блокируются

### Решение:

#### Вариант 1: Принять ограничение (Рекомендуется для большинства случаев)

**На Vercel используйте только `kodikLink`**, пусть клиенты получают прямые ссылки со своих IP-адресов.

Преимущества:
- ✅ Работает на бесплатном плане Vercel
- ✅ Клиенты получают прямые ссылки со своих IP
- ✅ Меньше нагрузки на сервер

Недостатки:
- ❌ Требует дополнительного запроса от клиента

#### Вариант 2: Альтернативный endpoint (Экспериментально)

Создан endpoint `/api/kodik/direct-links?kodik_link=...` который пытается парсить HTML страницу.

**ВНИМАНИЕ:** Скорее всего также будет заблокирован.

Пример:
```bash
curl "https://animelib-api.vercel.app/api/kodik/direct-links?kodik_link=https://kodik.info/seria/997479/..."
```

#### Вариант 3: Использовать внешний прокси-сервис

Интеграция с прокси-сервисами (требует дополнительных расходов):
- ScraperAPI (https://scraperapi.com)
- Bright Data (https://brightdata.com)
- Собственный VPS с прокси

#### Вариант 4: Другой хостинг (Наиболее надежно)

Переезд на хостинг с выделенными IP:

**VPS хостинги** (рекомендуется):
- **DigitalOcean Droplet** - $6/месяц, выделенный IP
- **Hetzner Cloud** - от €4.51/месяц  
- **Contabo VPS** - от €6.99/месяц
- **Oracle Cloud** - бесплатный tier с выделенным IP

Преимущества VPS:
- ✅ Выделенный IP адрес (не заблокирован Kodik)
- ✅ Полный контроль над окружением
- ✅ Нет таймаутов на функции
- ✅ Можно добавить кэширование

**PaaS хостинги** (могут быть заблокированы):
- Railway.app - может быть заблокирован
- Render.com - может быть заблокирован  
- Fly.io - есть выделенные IP

#### Вариант 5: Гибридное решение

1. Основной API на Vercel (бесплатно)
2. Микросервис для прямых ссылок на VPS ($6/месяц)
3. Vercel проксирует запросы к VPS для получения прямых ссылок

## Команды для деплоя:

```bash
# Установка зависимостей
npm install

# Запуск локально
npm run dev

# Сборка
npm run build

# Деплой на Vercel
vercel --prod
```

## Проверка работы:

Локально (должно работать):
```bash
curl http://localhost:3000/api/kodik/episode?episode_id=41924
```

На Vercel (может не работать без настройки):
```bash
curl https://your-project.vercel.app/api/kodik/episode?episode_id=41924
```
